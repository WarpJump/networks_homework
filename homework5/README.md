# TLS Chat Application

TCP-чат с использованием шифрования TLS 1.3. Реализована защита от MITM (проверка сертификата сервером) и логирование сессионных ключей.

## 1. Компиляция

Требуются библиотеки OpenSSL.

```bash
g++ main.cpp -lssl -lcrypto -o tls_chat
```

## 2. Генерация ключей

Для работы сервера и проверки на клиенте необходим самоподписанный сертификат.

```bash
./keygen.sh
```

## 3. Запуск

### Сервер
Запускается на указанном порту с путями к сертификату и ключу.

```bash
export SSLKEYLOGFILE=./ssl.log
./tls_chat server 8080 cert.pem key.pem
```

### Клиент
Подключается к хосту и порту. **Важно:** Клиенту передается `cert.pem` для верификации подлинности сервера.

```bash
export SSLKEYLOGFILE=./ssl.log
./tls_chat client 127.0.0.1 8080 cert.pem
```

## 4. Инструкция для расшифровки трафика (Wireshark)

Приложенный файл трафика `trace.pcapng` записан на порту **8080**. Поскольку это нестандартный порт для TLS, Wireshark требует ручной настройки.

1. **Для того чтобы пакеты отображались как TLC:**
На любом пакете с исходящим или входящем порту 8080 нажать правой кнопкой мыши -> **Decode As...** (Декодировать как...) -> в колонке "Current" изменить значение на **TLS**. Нажмать Save.


2.  **Для расшифровки трафика:**
    *   Перейти **Edit** -> **Preferences** (Правка -> Настройки).
    *   В списке **Protocols** выбрать **TLS**, в поле **(Pre)-Master-Secret log filename** указать путь к приложенному файлу **`ssl.log`**.
    *   Нажмите OK.

После этого во вкладке "Decrypted TLS" (внизу окна) станет доступно содержимое сообщений (13 и 15 пакеты содержат текст, записанный во время трассы)
